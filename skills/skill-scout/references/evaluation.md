# Как оценивать кандидатов

## Порядок важности

1. **Покрытие задачи.** Инструмент, без которого ключевая часть задачи не делается или
   делается заметно хуже, стоит выше приятного дополнения.
2. **Доверие к автору.**
3. **Свежесть.**
4. **Минимум прав** при равной пользе: из двух похожих выбирай тот, что просит меньше.

## Автор

| Уровень | Признаки |
| --- | --- |
| Вендор сервиса | Репозиторий в организации самого сервиса (`github.com/figma`, `github.com/stripe`); в реестре MCP — имя с доменом вендора (`com.figma.mcp/mcp`) |
| Anthropic | Репозиторий `anthropics/*`, автор Anthropic |
| Проверенный каталог | `claude-plugins-official`, `knowledge-work-plugins`, Anthropic Directory (`publisher.basis: directory_review` в `SearchPlugins`) |
| Сообщество | `claude-community`, известные авторы, много звёзд, живые issues |
| Неизвестный | Личный аккаунт, меньше 50 звёзд, нет лицензии или README. Рекомендуй только с ⚠ и если нет альтернатив |

Название маркетплейса говорит, кто ведёт каталог, а не кто написал плагин. В официальном
маркетплейсе есть и сторонние плагины.

## Свежесть

- Обновлялся за последние 6 месяцев — хорошо.
- 6–12 месяцев — нормально для стабильных инструментов.
- Больше 12 месяцев — ⚠ «давно не обновлялся».
- `archived`, `deprecated`, статус в реестре не `active`, описание-заглушка — не рекомендуй.

## Права и доступы

| Что показал `scout.py inspect` | Что это значит | Как реагировать |
| --- | --- | --- |
| Только skills, commands, agents | Инструкции для Claude, свой код не запускают | Без предупреждения |
| `allowed-tools` с узкими правилами | Заранее разрешённые команды на время хода скилла | Упомяни, если среди них Bash или Write |
| `allowed-tools: Bash` без ограничений, `Write`, `Edit` | Скилл запускает команды и правит файлы без вопроса | ⚠ |
| Хуки в `hooks/hooks.json` | Shell-команды на события, вне песочницы, с правами пользователя | ⚠, особенно PreToolUse и PostToolUse на каждое действие и SessionStart, который что-то скачивает |
| Мод (`modules` в `hooks.json`) | JavaScript внутри Claude Code с доступом к файлам, процессам и сети | ⚠ |
| Локальный MCP (`command`, npx, uvx, docker) | Процесс с правами пользователя | ⚠, если сервер даёт shell, файловую систему или управление браузером |
| Удалённый MCP (`url`) | Данные уходят во внешний сервис | Назови сервис; ⚠, если нужен токен или OAuth с широкими правами |
| `bin/` | Исполняемые файлы в PATH для Bash | ⚠ |
| Токены и секреты (`env`, `headers`, `userConfig` с `sensitive`) | Нужен доступ к аккаунту | Скажи, какой токен нужен и каких минимальных прав хватит |
| `reach: privileged` в `SearchPlugins` | Каталог сам отмечает повышенные права | ⚠ |

## Признаки сомнительного источника

- Установка через `curl | sh` или скачивание бинарника без проверки подписи.
- Имя пакета в npm или PyPI не совпадает с репозиторием или автором.
- Форк популярного проекта без заметных отличий, свежий репозиторий без истории.
- Инструкции просят отключить проверки безопасности или запускать
  `--dangerously-skip-permissions`.

## Как писать предупреждение

Одна строка: что именно и чем это грозит.

- «⚠ Хуки запускают python-скрипт после каждого Bash и Edit»
- «⚠ Локальный сервер с доступом к терминалу и файлам»
- «⚠ Нужен Personal Access Token Figma; хватит прав только на чтение»
- «⚠ Частный автор, 12 звёзд, не обновлялся с 2024-11»
